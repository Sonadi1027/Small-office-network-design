Small Office Network Design

Project Overview

A small office network designed and simulated using Cisco Packet Tracer. The network separates three departments using VLANs and enables communication between them through inter-VLAN routing.

Network Departments

 Department    VLAN ID   Network 
 ADMIN         10        192.168.10.0/24 
 IT            20        192.168.20.0/24 
 FINANCE       30        192.168.30.0/24 

Technologies

- Cisco Packet Tracer
- VLANs and trunking
- Router-on-a-stick
- Inter-VLAN routing
- Switch port security

Security Features

- Sticky MAC address learning on PC ports
- Port security with a maximum of one secure MAC address per port
- Shutdown action for security violations
- Unused switch ports disabled

Testing

Ping tests were performed to verify connectivity between router gateways and PCs in different VLANs.

Project Structure

- Packet-tracer — Network simulation file
- Screenshots — Network topology and connectivity evidence
- Documentation — Configuration notes

Learning Outcomes

Practiced VLAN configuration, trunking, inter-VLAN routing, basic switch security, and network troubleshooting.
